# Albert Sans

Self-hosted variable Albert Sans (100–900), Latin and Latin Extended WOFF2.
Distributed under the SIL Open Font License in `albert-sans/LICENSE.txt`.
Source: [Fontsource Albert Sans 5.3.0](https://www.npmjs.com/package/@fontsource-variable/albert-sans/v/5.3.0), from [the Albert Sans project](https://github.com/usted/Albert-Sans).
No third-party font requests are made at runtime.
