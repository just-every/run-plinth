# Estimate productivity and sales

Open Jobs, then Estimate productivity and sales. The report includes only jobs allowed by the current reader's grants. Costs and production sources require financial, estimate, budget, schedule, purchasing and time visibility. Private catalog definitions and lesson proposals retain the existing catalog permissions. Removing those rights takes effect on the next request, including comparison downloads.

Record completion with a date and evidence after every booked task has an actual finish. This records the builder's decision; it does not certify physical completion. Completed jobs compare the accepted estimate with posted costs, approved labor minutes and the latest installed quantities. Each code names its original assembly revision and recorded trade, with quote lines, cost entries, time records and actual-work references available in Download comparison sources. Amounts retain their job currency.

Estimated labor uses the original assembly conversion and hourly rate unit. Actual productivity divides compatible installed units by approved labor hours. Missing quantities, incompatible units and unallocated sources remain Unknown. Pending labor is excluded. A transferred labor allocation needs reconciliation before its production denominator is known. A code shared by multiple assemblies is explicitly unallocated rather than inventing an allocation.

Sales stages are Qualified, Estimating, Submitted, Negotiating, Lost and Won. Staff record the current proposal's stage, evidence and reason explicitly. Won comes from the immutable recorded client acceptance. A new proposal revision does not inherit an older proposal's loss. Win rates count distinct jobs with a current won or lost outcome for the current proposal's preparer; open work stays outside that denominator. Pipeline amounts remain separate by currency. Bid reports use the current published package revision, non-revoked invitations, source response identities and active awards; canceled awards remain outside the active award count.

Catalog managers prepare lessons from at least two completed jobs in the same currency and propose an assembly or estimate-template revision. Proposal alone changes no catalog. An authorized catalog manager reviews the exact definition and explicitly approves it for new estimates. Approval checks the source job versions and catalog revision in the same transaction, records attribution, and appends a catalog revision. Changed or erased sources require a fresh proposal. Repeating an approved decision cannot append another revision. Existing quote revisions, accepted proposals, budgets and posted costs remain fixed; a new draft estimate requires its ordinary template preview and approval.

These are native recorded outcomes. This report does not claim external lead intake, provider synchronization or physical-work verification.
