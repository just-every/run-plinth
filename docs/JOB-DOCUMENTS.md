# Private job and company documents

The owner opens a job's **Documents** tab to keep original files. Documents,
Photos and Videos each have their own folders. Create Contracts, Permits and
Warranties, or nest a folder under another folder in the same area.

Choose **Upload a file**, its folder, a document name and optional comma-separated
tags. Originals up to 2 MB are retained as supplied. Photos accept PNG and JPEG;
Videos accept MP4 and WebM. Other files are downloaded as attachments. Every
version keeps its uploader, upload time, byte count and SHA-256 checksum. Adding
a version preserves all earlier versions and their download links. The name
search includes original filenames; the tag search matches a complete tag.

**Link a private version to a record** selects an exact version and an existing
record in the same job. The owner sees its link in the corresponding record
section. Draft handover packages can be linked too. The link does not copy the
file into a published record or handover package and grants no external access.

Company templates and standard originals live in **Company documents** under
**People & access**, independently of job folders. Native private archives carry
both libraries and all their originals. Job erasure removes that job's versions
and links; independent company templates remain. A later erasure journal fences
older archives using the existing native restore process.

This interim library is owner-only. Administrator and custom-role access,
client and subcontractor grants, selected-company and all-subcontractor sharing,
visible sharing controls, revocation and publication of these private originals
remain unfinished under DOC-007, ROLE-003 and ROLE-006. Existing structured plan
and handover sharing retain their own permissions.
